# app-policies

Privacy policies, terms of use and support information for three iPhone apps by an independent developer: Game Night Atlas, Deckling and Cursive Kitchen. This is a plain static site (HTML plus one shared `style.css`; no JavaScript, external fonts or trackers; light and dark mode follow the device) published with GitHub Pages at https://wmflxmwm-cell.github.io/app-policies/. The apps link directly to `game-night-atlas/privacy.html`, `deckling/privacy.html`, `cursive-kitchen/privacy.html` and `cursive-kitchen/terms.html`, so keep those paths unchanged; `support.html` is the support URL for App Store Connect, and `.nojekyll` makes GitHub Pages serve the files as they are. All pages take effect on October 11, 2026; when an app's data handling changes, update its policy and the effective date together.
